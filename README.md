# Barrio Claro

Prototipo para Hack Apertus. Reduce avisos públicos a: qué cambia, para quién y qué hacer ahora. No completa datos ausentes.

Estado: flujo local probado con respuestas simuladas. La integración real requiere endpoint y credencial oficiales. No registra avisos, datos personales ni claves.

El navegador envía texto a POST /api/explain. El servidor usa APERTUS_ENDPOINT y APERTUS_API_KEY solo en el entorno.

El premio es competitivo y no está garantizado.
